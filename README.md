# قیمت واقعی بنزین

Persian interactive data story. Static site, no build step, no external requests (fonts are bundled).

- `index.html`: the article
- `assets/data.js`: chart data, generated by `../scripts/build_site_data.py` from `../data/`
- `assets/charts.js`: small SVG chart library; `assets/app.js`: charts, calculator, loop diagram
- `assets/fonts/`: Vazirmatn (SIL Open Font License)

Publish: push this folder's contents to the `gasoline-true-price` repo and enable GitHub Pages (branch `main`, root).
